Este repositório reúne minhas resoluções dos exercícios propostos pelo professor **Gustavo Guanabara** no curso de **Python 3** da plataforma [Curso em Vídeo](https://cursoemvideo.com).

## 📚 Conteúdo Programático

### 🌍 Mundo 1: Fundamentos
Introdução à linguagem, instalação e primeiros comandos.
* **Tipos primitivos e saída de dados:** `int`, `float`, `bool`, `str` e formatação de strings.
* **Operadores aritméticos:** Cálculos básicos, ordem de precedência e operadores especiais.
* **Utilizando módulos:** Importação de bibliotecas como `math`, `random` e `pygame`.
* **Manipulando texto:** Fatiamento, análise e transformação de strings.
* **Condições simples e compostas:** Estruturas `if` e `else`.

### 🌍 Mundo 2: Estruturas de Controle
Aprofundamento na lógica de programação e tomada de decisões.
* **Condições aninhadas:** Uso de `elif` para múltiplas verificações.
* **Repetições com `for`:** Laços com variável de controle e contagem.
* **Repetições com `while`:** Laços com teste lógico no início e interrupções com `break`.

### 🌍 Mundo 3: Estruturas Compostas
Manipulação de coleções de dados, modularização e boas práticas.
* **Tuplas:** Variáveis compostas imutáveis.
* **Listas:** Variáveis compostas mutáveis (Parte 1 e Parte 2 - listas compostas).
* **Dicionários:** Estruturas com índices literais (chave e valor).
* **Funções:** Criação de rotinas personalizadas (`def`), parâmetros, escopo e retorno (Parte 1 e Parte 2).
* **Modularização e Pacotes:** Organização de código em múltiplos arquivos.
* **Tratamento de Erros e Exceções:** Uso de `try`, `except`, `else` e `finally`.

### 💻 Diretório de Exercícios (001 - 100)
Pasta centralizada contendo os **100 primeiros exercícios** resolvidos e comentados, numerados sequencialmente (`ex001.py` até `ex100.py`), acompanhando a evolução dos três mundos.

## 🚀 Como executar os códigos

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
3. Acesse a pasta desejada e execute qualquer arquivo `.py` pelo terminal ou pela sua IDE favorita (VS Code, PyCharm, etc.):
   ```bash
   python ex001.py
   ```
